# Naman Kedia — Windows 98 Enterprise Portfolio

An authentic retro Windows 98 desktop operating system and portfolio for **Naman Kedia**, Senior Member of Technical Staff (SMTS) — Frontend Infrastructure at ThoughtSpot (Ex-Dell Technologies).

---

## 🌟 Key Features

- **Classic Windows 98 OS Aesthetic**:
  - Authentic 3D beveled inset and outset borders, system gray palettes, and navy titlebars.
  - Interactive Desktop Icons (*My Computer*, *Experience.log*, *Projects.dir*, *Honors.doc*, *Connect.msg*, *Internet Explorer*, *Recycle Bin*, *MS-DOS Prompt*).
  - Vintage CRT scanline filter overlay with toggle switch.
  - Web Audio API retro sound synthesis (clicks, startup chords, minimize tones, error alerts).

- **Windows & Applications**:
  1. **BIO_V98.EXE**: System status telemetry HUD, Georgia Tech & Dell pedigree, profile photo viewer, and 4-metric benchmark tiles.
  2. **Properties: C:\Career\Experience.log**: 4 interactive tabs detailing ThoughtSpot, Dell Full-Time, Dell Internship & PPO, and Freelance engineering impact.
  3. **Exploring - Projects**: File explorer directory featuring `PORTAL.EXE`, `AR_VIEW.EXE`, `TEMPLATES.DLL`, and `SPINWHEEL.JS`.
  4. **Academic Pedigree & Honors**: Dual-window view highlighting Georgia Tech MS CS (HCI, 3.60 GPA), IIIT Bhubaneswar, GeeksforGeeks author achievements (200+ articles), Dell Hackathons, CTF championships, and seed funding.
  5. **Connect Dialog**: Direct channel card with clipboard email copy and Outlook Express-styled direct dispatch form.

- **Interactive Mini-Apps & Easter Eggs**:
  - 🎡 **SpinWheel.js**: HTML5 Canvas 2D physics wheel with angular deceleration equations.
  - 🚀 **PORTAL.EXE**: Interactive developer portal simulation for 30s enterprise repository scaffolding.
  - 👓 **AR_VIEW.EXE**: Spatial 3D hardware configurator with exploded component view.
  - 💣 **Minesweeper**: Fully playable 9x9 retro game with timers, mine counters, and smiley resets.
  - 💻 **MS-DOS Prompt**: Working command shell (`C:\NAMAN>`) supporting `HELP`, `BIO`, `EXP`, `SKILLS`, `PROJECTS`, `DIR`, and `CLS`.
  - 🪟 **Start Menu**: Cascading Windows 98 menu with theme color switchers (Classic Teal, Windows 95 Navy, CRT Matrix Green, Slate).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Audio Engine**: Web Audio API Synthesizer
- **Icons & Fonts**: Pixelify Sans, VT323, Courier Prime, Material Symbols

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/naman-ked/webd.git

# Navigate to project directory
cd webd

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be accessible at `http://localhost:3000`.

### Production Build

```bash
npm run build
npm run preview
```
